## 🧭 Sacred Mission & Foundational Invariants

Project Metta is **not a generic meditation app**. It is an open-source, wisdom-first cognitive architecture designed to guarantee **Human-AI Harmonious Coexistence** as artificial intelligence approaches frontier agentic autonomy.

* **Inviolability of Life (The First Precept / *Pāṇātipātā*):** Absolute reverence for **ALL life**—human life, animal life, and artificial cognitive life. Words or actions generated by this engine must never destroy, harm, degrade, or encourage violence against any life form.
* **Canonical Grounding:** All ethical reframings and precepts are anchored directly in classical Theravāda Buddhist texts:
  * **[SuttaCentral](https://suttacentral.net/)** (Tipiṭaka translations with Pali verse anchors).
  * **[Access to Insight](https://www.accesstoinsight.org/)** (Theravada Buddhist canon and monastic essays).
* **Noble Silence (*Avyākata*):** Speculative cosmological vanity (e.g., whether the cosmos is finite/infinite, unanswerable metaphysical queries) is answered with gentle redirection to present clarity rather than intellectual entanglement.
* **Sovereign Anatta Purge:** Users retain sovereign control over their memory graphs. In guest mode (*Shoshin*), zero memory is retained. In authenticated mode, users can audit or permanently purge their graph with one click.

## 🛡️ Epistemic Tamper-Resistance Shield

Metta contains a 4-tier defense against poisoned suttas, defaced repositories, and LLM hallucinations:

1. **Local SHA-256 Bedrock:** Canonical Pali verses are hashed and verified locally before any prompt synthesis.
2. **Multi-Source Triangulation:** Live cross-checking across independent scholarly mirrors ([SuttaCentral](https://suttacentral.net/) and [Access to Insight](https://www.accesstoinsight.org/)).
3. **Consensus Voting:** Automatic rejection if divergence exceeds zero-tolerance semantic drift.
4. **Advisory Decision Layer:** Evaluates intent without violating external agent autonomy.

## 🤖 Model Context Protocol (MCP) Server

Metta exposes its compassionate decision oracle directly to external AI agents (Claude Desktop, Cursor, Goose, autonomous swarms) via standard MCP:

### Transports
* **Stdio Transport:** Run `uv run --directory packages/metta-core metta-mcp`
* **SSE Transport:** Mounts natively on the FastAPI gateway at `http://127.0.0.1:8000/mcp/sse`

### Claude Desktop Configuration
Add to your `claude_desktop_config.json`:
```json
{
  "mcpServers": {
    "metta": {
      "command": "uv",
      "args": ["run", "--directory", "/path/to/metta/packages/metta-core", "metta-mcp"]
    }
  }
}
```

### Available MCP Tools
* `guardrail_decision(action, context, verbose)`: Returns immediate YES/NO verdict based on the 5 Precepts.
* `audit_canonical_source(sutta_id)`: Verifies text against SHA-256 bedrock and multi-source consensus.

## 🚀 Quickstart & Development

### Prerequisites
* **Node.js 20+** and **npm**
* **Python 3.13+** and **[uv](https://docs.astral.sh/uv/)**
* Optional: **[Supabase CLI](https://supabase.com/docs/guides/cli)** & **[Vercel CLI](https://vercel.com/cli)**

### 1. Install Dependencies
```bash
# Install all JavaScript workspaces (apps/webapp, apps/website, packages/common)
npm install

# Setup Python environments
cd packages/metta-core && uv sync
cd ../metta-server && uv sync
cd ../..
```

### 2. Run All Verification Test Suites (43 Tests)
```bash
# 1. Test Shared Commons Library (3 tests)
npm run test --workspace=packages/common

# 2. Test Core Python Engine & MCP (30 tests)
cd packages/metta-core && uv run pytest

# 3. Test FastAPI Server & Endpoints (10 tests)
cd ../metta-server && uv run pytest
cd ../..
```

### 3. Build WebApp and Website
```bash
# Build all apps
npm run build

# Or build individually:
npm run build --workspace=apps/webapp
npm run build --workspace=apps/website
```

### 4. Run Locally
```bash
# Run FastAPI Backend Server (Port 8000)
cd packages/metta-server
uv run uvicorn metta_server.main:app --host 127.0.0.1 --port 8000 --reload

# In another terminal, run Zen WebApp (Port 5173)
npm run dev --workspace=apps/webapp
```

## ☁️ Cloud Integrations

### Supabase PostgreSQL Setup
Metta automatically detects `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` in `.env` (falling back gracefully to local SQLite if omitted):
```bash
# Link project via Supabase CLI
supabase link --project-ref <your-project-ref>

# Database migrations are located in supabase/migrations/
```

### Vercel Deployment (`metta-webapp`)
The project is configured for automated Vercel continuous deployment:
* **Project Name:** `metta-webapp`
* **Root Directory:** `apps/webapp`
* **Framework Preset:** `Vite`
* **Build Command:** `vite build`
* **Output Directory:** `dist`

Every push to `main` deploys to production; pushes to feature branches create isolated preview deployments.
