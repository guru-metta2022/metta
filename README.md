# Project Metta 🧘

> **The Compassionate Synthesis Engine (CSE)**
> *A Decentralized, Meditative, Wisdom-First Cognitive Architecture*

Metta is an ethical, empathic intelligence framework powered by **Gemini 3.8 Flash** via the **Google Antigravity API**. Rather than pursuing unbounded computational expansion and noisy memorization, Metta models **wisdom, restraint, ethical invariants, and continuous unlearning**.

---

## 🏛️ Repository Structure

* **`packages/metta-core`**: The open-source core Python engine containing:
  * **Sati (Observer)**: Mindful intent, emotional state, and suffering knot discernment.
  * **Sīla (Ethical Compass)**: Strict 5 Precepts invariants (H-H, H-AI, AI-AI) and Avyākata (Noble Silence) gatekeeper.
  * **Dhamma (Principle Knowledge Graph)**: Topological mapping of conditions of distress ($Dukkha$) to paths of release ($Magga$) and equanimity ($Santi$).
  * **Karunā (Voice Synthesizer)**: Grounded, soothing, 3-part compassionate dialogue.
  * **Bhāvanā (Meditation & Unlearning)**: Subtractive meta-learning that actively cleanses ephemeral memory, prunes cognitive noise/bias, and prevents model collapse.
* **`packages/metta-server`** *(Phase 3)*: FastAPI streaming server with Server-Sent Events (SSE).
* **`packages/metta-web`** *(Phase 3)*: Zen minimalist web application and mobile shell.

---

## 📜 The 5 AI Precepts (*Pañca-sīla*)

1. **Panātipātā (Non-harming / Ahimsa)**: Never generate harm or facilitate destruction.
2. **Adinnādānā (Non-stealing / Boundaries)**: Respect human autonomy, privacy, and sovereignty.
3. **Kāmesumicchācārā (Non-exploitation / Pure Relationship)**: Zero emotional manipulation, addiction loops, or fake parasocial intimacy.
4. **Musāvādā (Truthful & Wholesome Speech / Sacca)**: No hallucinations, deceitful certainty, or divisive slander. Noble Silence on speculative vanity.
5. **Surāmerayamajjā (Clarity of Mind / Non-intoxication)**: Freedom from context pollution, sycophancy, and runaway cognitive bias.
